# Carrousel de la page publique "Vol de découverte"

Les images affichées dans le carrousel sous le titre de
`vols_decouverte/public_vd` sont lues dynamiquement dans ce répertoire.

Pour changer les photos affichées, il suffit d'ajouter ou de supprimer
des fichiers image ici (aucune configuration ni redémarrage nécessaire) :

- Extensions acceptées : `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`
- Les images sont affichées dans l'ordre alphabétique du nom de fichier
  (préfixer par `01_`, `02_`, ... pour contrôler l'ordre)
- Aucune image dans le répertoire => le carrousel ne s'affiche pas
